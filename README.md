# TaskFlow

A team task management app where users create projects, assign tasks, and collaborate through comments. Access is role-based (Admin, Manager, Member).

## Tech Stack
- Backend: ASP.NET Core Web API (C#), Entity Framework Core
- Database: SQL Server
- Frontend: Angular, TypeScript
- Auth: JWT with refresh tokens, ASP.NET Identity

## Planned Features
- User registration and login
- Projects, tasks and comments
- Role-based authorization
- Docker, CI/CD (GitHub Actions) and Azure deployment
- Notifications via a message queue, Redis caching

## Status
Work in progress. Built as a learning project, updated weekly.
